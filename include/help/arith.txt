*arith* *arithmetic* *arithmetic-expansion*

#ARITHMETIC EXPANSION#

Arithmetic expansion evaluates a mathematical expression and substitutes
the result. The expression is subject to parameter expansion and command
substitution before evaluation.

  `$((expression))`

      Example:
        `echo $((2 + 3))`       # prints: 5
        `x=$((width * height))`

==============================================================================
1. Operators                                   *arith-operators*

  The following operators are supported, listed from highest to lowest
  precedence:

  `( )`                                        *arith-parens*

      Grouping. Override default precedence.

      Example:
        `echo $(( (2+3) * 4 ))`  # prints: 20

  `**`                                         *arith-pow*

      Exponentiation. Right-associative, and binds tighter than `* / %`
      but looser than unary minus (so `-2**2` is `(-2)**2` == 4). A
      negative exponent is an error.

      Example:
        `echo $((2 ** 10))`      # prints: 1024
        `echo $((2 ** 2 ** 3))`  # prints: 256

  `*` `/` `%`                                  *arith-muldivmod*

      Multiplication, division, and modulo (remainder).

      Example:
        `echo $((10 / 3))`       # prints: 3
        `echo $((10 % 3))`       # prints: 1

  `+` `-`                                      *arith-addsub*

      Addition and subtraction.

      Example:
        `echo $((10 - 3 + 1))`   # prints: 8

==============================================================================
2. Variables in Expressions                    *arith-variables*

  Variables can be referenced by name inside arithmetic expressions.
  They are expanded and converted to numbers.

      `x=10`
      `echo $(($x + 5))`        # prints: 15
      `echo $((x + 5))`         # also works

  An unset (or empty) variable counts as 0. A variable whose value is
  not a plain integer is itself evaluated as an arithmetic expression,
  so references resolve transitively:

      `x=3; y=x;   echo $((y + 1))`   # prints: 4  (y -> x -> 3)
      `a=2; b=a+1; echo $((b * 2))`   # prints: 6

  A self- or mutual reference (`x=x`, `a=b; b=a`) is an error rather
  than an infinite loop.

==============================================================================
3. Number formats                              *arith-numbers*

  Integer literals may be written as:

      decimal           `42`
      hexadecimal        `0x` / `0X` prefix, e.g. `0xff` == 255
      octal              leading `0`, e.g. `0755` == 493
      radix              `base#digits`, base 2..64, e.g. `2#101` == 5,
                         `16#ff` == 255, `36#z` == 35

  For `base#digits`, digits 0-9 then letters carry values 10 and up. For
  bases up to 36 letters are case-insensitive; for larger bases `a-z` are
  10-35, `A-Z` are 36-61, `@` is 62 and `_` is 63.

==============================================================================
4. Nesting                                     *arith-nesting*

  Arithmetic expressions can be nested with parentheses to any depth:

      `echo $(( (1+2) * (3+4) ))`  # prints: 21

  Arithmetic expansion can also appear inside other expansions:

      `echo "Total: $((price * qty))"`

==============================================================================
5. Whitespace                                  *arith-whitespace*

  Whitespace inside `$((...))` is ignored and can be used freely for
  readability:

      `echo $((2+3))`           # prints: 5
      `echo $(( 2 + 3 ))`       # same result
